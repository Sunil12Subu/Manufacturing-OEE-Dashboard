Dashboard Purpose

Why this dashboard is required?

Because manufacturing loses money every single minute without knowing where and why.

Key Questions This Dashboard Answers:

  • Are machines available?
  • Are they running at the right speed?
  • Are we producing good quality?
  • Where exactly are we losing time and money?

Target Audience

Consumer of this dashboard:

  • Plant Manager
  • Production Manager
  • Operations Head
  • Shift Supervisor
  • Continuous Improvement / Lean Team

Authority Level

The person using this dashboard typically has authority to:

  • Approve overtime
  • Add or remove operators
  • Change shift planning
  • Approve maintenance windows
  • Prioritize process improvement projects
  • Escalate issues to leadership

KPI Definitions & DAX Formulas

Availability

Definition

When we planned to run the machine, how much time did it ACTUALLY run?

Business Relevance

Availability shows how often our machines were available for production instead of being stopped.

DAX Formula: Availability %

Availability % = 
VAR TotalPlannedTime = SUM(FactProductionLog[PlannedProductionTime_Minutes])
VAR TotalDowntime = SUM(FactProductionLog[DownTime_Minutes])
VAR TotalRunTime = TotalPlannedTime - TotalDowntime
VAR Availability = 
    IF(
        TotalPlannedTime = 0,
        BLANK(),
        DIVIDE(TotalRunTime, TotalPlannedTime, 0)
    )
RETURN
    Availability

DAX Formula: Availability vs Last Week Text

Availability vs Last Week Text = 

VAR CurrentOEE = [Availability %]
VAR LastWeekOEE = 
    CALCULATE(
        [Availability %],
        DATEADD(DimDate[FullDate], -7, DAY)
    )
VAR Variance_ = CurrentOEE - LastWeekOEE

VAR VariancePP = Variance_ * 100          -- convert to pp
VAR Arrow =
    IF (
        Variance_ > 0,
        UNICHAR(9650),   -- ▲
        UNICHAR(9660)    -- ▼
    )
VAR Sign =
    IF ( Variance_ > 0, "+", "" )
RETURN
    IF (
        ISBLANK ( Variance_ ),
        "No comparison data",
        Arrow & " "
            & Sign
            & FORMAT ( VariancePP, "0.00" )
            & " pp vs Last Week"
    )

DAX Formula: Availability vs Last Week Color

Availability vs Last Week color = 

VAR CurrentOEE = [Availability %]
VAR LastWeekOEE = 
    CALCULATE(
        [Availability %],
        DATEADD(DimDate[FullDate], -7, DAY)
    )
VAR Variance_ = CurrentOEE - LastWeekOEE
return 
IF( Variance_ > 0 ,1 ,0)

Performance

Definition

This performance measure compares how much time production should have taken at ideal speed versus how much time it actually took.

DAX Formula: Performance %

Performance % = 
VAR TotalRunTime = SUM(FactProductionLog[ActualRunTime_Minutes]) * 60  // Convert to seconds
VAR TotalUnits = SUM(FactProductionLog[TotalUnitsProduced])
VAR IdealCycleTime = 
    SUMX(
        FactProductionLog,
        FactProductionLog[TotalUnitsProduced] * FactProductionLog[IdealCycleTime_Seconds]
    )
VAR Performance = 
    IF(
        TotalRunTime = 0,
        BLANK(),
        DIVIDE(IdealCycleTime, TotalRunTime, 0)
    )
RETURN
    Performance

Quality

Definition

Quality tells us what percentage of produced units are good and saleable.

Business Relevance

Poor quality means we are producing waste. Quality shows how much of our production actually turns into revenue.

DAX Formula: Quality %

Quality % = 
VAR TotalUnits = SUM(FactProductionLog[TotalUnitsProduced])
VAR GoodUnits = SUM(FactProductionLog[GoodUnitsProduced])
VAR Quality = 
    IF(
        TotalUnits = 0,
        BLANK(),
        DIVIDE(GoodUnits, TotalUnits, 0)
    )
RETURN

Overall Equipment Effectiveness (OEE)

Definition

OEE shows how effectively we are using our machines to make good products at the right speed.

Business Relevance

OEE is a single number that tells leadership how healthy production really is.

Availability tells us if machines are running, Performance tells us how fast they run, and Quality tells us how much of that output actually makes money.

DAX Formula: Overall OEE

Overall OEE = 
VAR Availability = [Availability %]
VAR Performance = [Performance %]
VAR Quality = [Quality %]
VAR OEE = Availability * Performance * Quality
RETURN
    IF(
        ISBLANK(OEE),
        BLANK(),
        OEE
    )

DAX Formula: OEE vs Last Week

OEE vs Last Week = 
VAR CurrentOEE = [Overall OEE]
VAR LastWeekOEE = 
    CALCULATE(
        [Overall OEE],
        DATEADD(DimDate[FullDate], -7, DAY)
    )
VAR Variance_ = CurrentOEE - LastWeekOEE
RETURN
    IF(
        ISBLANK(Variance_),
        BLANK(),
        Variance_
    )

DAX Formula: OEE vs Last Week Text

OEE vs Last Week Text = 
VAR Variance_ = [OEE vs Last Week]        -- decimal (e.g. 0.005)
VAR VariancePP = Variance_ * 100          -- convert to pp
VAR Arrow =
    IF (
        Variance_ > 0,
        UNICHAR(9650),   -- ▲
        UNICHAR(9660)    -- ▼
    )
VAR Sign =
    IF ( Variance_ > 0, "+", "" )
RETURN
    IF (
        ISBLANK ( Variance_ ),
        "No comparison data",
        Arrow & " "
            & Sign
            & FORMAT ( VariancePP, "0.00" )
            & " pp vs Last Week"

DAX Formula: OEE vs Last Week Color

OEE vs Last Week color = IF( [OEE vs Last Week] > 0 ,1, 0)

Six Big Loss Analysis

Definition

This chart tells us which loss categories are contributing the most to total downtime and how quickly those losses accumulate.

DAX Formula: Total Downtime Minutes

Total Downtime Minutes = 
SUM(FactDowntime[DurationMinutes])

DAX Formula: Cumulative Downtime %

Cumulative Downtime % = 
VAR CurrentCategory = MAX(DimDowntimeReason[LossCategory])
VAR CurrentDowntime = [Total Downtime Minutes]
VAR AllCategories = 
    ADDCOLUMNS(
        SUMMARIZE(
            ALLSELECTED(FactDowntime),
            DimDowntimeReason[LossCategory]
        ),
        "@Downtime", [Total Downtime Minutes]
    )
VAR RankedCategories = 
    ADDCOLUMNS(
        AllCategories,
        "@Rank", 
        RANKX(
            AllCategories,
            [@Downtime],
            ,
            DESC,
            DENSE
        )
    )
VAR CurrentRank = 
    MAXX(
        FILTER(
            RankedCategories,
            [LossCategory] = CurrentCategory
        ),
        [@Rank]
    )
VAR CumulativeSum = 
    SUMX(
        FILTER(
            RankedCategories,
            [@Rank] <= CurrentRank
        ),
        [@Downtime]
    )
VAR TotalDowntime = [Total Downtime All Categories]
RETURN
    DIVIDE(CumulativeSum, TotalDowntime, 0)

Top Downtime Equipment

Definition

This Top Downtime Equipment analysis helps managers identify the single most damaging downtime event and prevent it from happening again.

DAX Formula: Max Downtime (hrs)

Max Downtime (hrs) = MAX( FactDowntime[Durationhours])

DAX Formula: Reason for Max Downtime

Reason for Max Downtime = 
VAR MaxEvent =
    TOPN(
        1,
        FactDowntime,
        FactDowntime[DurationHours], DESC
    )
RETURN
    MAXX(
        MaxEvent,
        RELATED(DimDowntimeReason[ReasonDescription])
)

Equipment Performance

DAX Formula: Get_min_of_oee

Get_min_of_oee = MIN([Overall OEE], [OEE Target])

DAX Formula: target_not_met_oee

target_not_met_oee = if ( [Overall OEE] < [OEE Target], MAX([OEE Target], [Overall OEE]) - [Get_min_of_oee])

DAX Formula: Achived_oee

Achived_oee = if ( [Overall OEE] > [OEE Target], MAX([Overall OEE], [OEE Target])-[Get_min_of_oee])

KPI Metric Summary

DAX Formula: KPI Selector

KPI Selector = 
DATATABLE(
    "Metric", STRING,
    {
        {"OEE Gap vs Target"},
        {"Worst Shift"},
        {"Lost Units"},
        {"Top Downtime Reason"},
        {"Availability Loss (hrs)"}
    }
)

Metric 1: OEE Gap vs Target

Definition: How far we are above or below the expected OEE target.

OEE Gap (pp) = [Overall OEE] - [OEE Target]

Metric 2: Worst Shift

Definition: The shift with the lowest performance or highest losses.

Worst Shift = 
VAR T =
    TOPN(
        1,
        VALUES(DimShift[ShiftName]),
        [Overall OEE], ASC
    )
RETURN
    MAXX(T, DimShift[ShiftName])

Metric 3: Lost Units

Definition: Number of units not produced due to downtime, slow speed, or quality losses.

Lost Units = 
DIVIDE(
    SUM(FactProductionLog[DownTime_Minutes]) * 60,
    AVERAGE(FactProductionLog[IdealCycleTime_Seconds])
)

Metric 4: Top Downtime Reason

Definition: The single most frequent or impactful reason causing downtime.

Top Downtime Reason = 
VAR TopEvent =
    TOPN(
        1,
        FactDowntime,
        FactDowntime[DurationHours], DESC
    )
RETURN
    MAXX(
        TopEvent,
        RELATED(DimDowntimeReason[ReasonDescription])
    )

Metric 5: Availability Loss (hrs)

Definition: Total hours lost when machines were planned to run but were stopped.

Availability Loss (hrs) = 
SUM(FactProductionLog[DownTime_Minutes]) / 60
